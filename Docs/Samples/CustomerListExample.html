Customer Lookup

Feature documentation for Customer Lookup, written by its BDD feature tests.

The application

Customer Lookup is a desktop application for the front office. Before a clerk takes on a new customer, they search the customer list by name to see whether the customer is already on file. That keeps one record per customer, so service history, invoices and contact details stay together.

A search shows every customer whose name matches, or tells the clerk that no customer was found. Searching never changes the customer list.

Who uses it

  • Clerks search the list while taking a call or filling in a new customer form.
  • Office managers use this document to see which features are ready and which are still in development.

This document

Each feature below was written as Given / When / Then scenarios before the code that makes them pass, and the scenarios are run against the application by its test suite.

  • Each feature shows when it was last run and where it is in its life cycle, from Proposed to Accepted, and the requirement it satisfies.
  • Each scenario shows whether it Passed or Failed, with the reason when it failed.
